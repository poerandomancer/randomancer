1. Future weapon legality should use structured weapon requirements as the hard boundary, then rank EXACT_NATIVE above EXPLICIT_BROAD_LEGALITY above UNRESTRICTED_CROSS_AFFINITY. This preserves weapon identity without discarding explicitly legal unusual constructions.
2. Future Tier 3 should first prove the minimal required support chain, then independently fill an optional optimizer slot. Optional modifiers must never bootstrap fulfillment, and prevention/consumption must override name or affinity matches.
3. Runtime DIRECT, CARRIER_BRIDGE, FALLBACK, support slots, persistent/Spirit policy, and weapon gating were not changed by this diagnostic. No named-skill or Weapon × Offense exceptions were introduced.
